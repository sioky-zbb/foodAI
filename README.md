# 轻食 Lens（FoodLens）

一个给 iPhone 用的减脂记录 PWA（渐进式 Web 应用）：拍照识别食物、AI 估重、自动计算热量与三大营养素、记录每日饮食并给出 AI 点评。不需要上架 App Store、不需要越狱、不需要 Mac/Xcode。

## 功能

- **拍照/相册识别**：用系统相机拍照或从相册选图，GLM 视觉模型识别图中所有食物
- **文字记录**：输入自然语言描述（如「一杯牛奶、一个鸡蛋、半碗米饭」），
  AI 自动识别食物并估重，无需拍照
- **AI 估重与营养**：DeepSeek 结合工牌比例尺、常见份量参考库估算每项食物的重量和热量/蛋白/碳水/脂肪
- **参照物比例尺**：把工牌（11.2 × 6.8 cm）或身份证放在食物旁，AI 以它为比例尺估算食物实际尺寸；支持俯拍 + 前上 45° 双视角（简易 3D 体积估算）
- **包装食品识别**：自动读取包装上的净含量/规格（如 275 克/15 个），配合「数量」输入自动折算总重
- **自定义食物库**：手动添加常吃食物，可直接拍摄营养成分表自动识别（每 100 克数值），设置一份重量后一键加餐
- **模糊匹配**：食物库支持模糊搜索；拍照/文字识别时也会对食物库和内置参考库做模糊匹配
- **每日记录**：按餐次记录，自动汇总当天总热量和蛋白质/碳水/脂肪
- **AI 饮食点评**：结合训练计划和当日饮食，让 AI 给出简短可执行的建议
- **身体数据**：记录体重、胸围、腰围、臀围，显示体重趋势图
- **本地存储**：所有数据保存在手机浏览器本地（IndexedDB），支持导出/导入 JSON 备份

## 技术栈

- 纯前端 PWA：HTML + CSS + JavaScript，无后端、无数据库
- Service Worker 缓存，安装后界面可离线打开
- IndexedDB 本地存储
- 智谱 GLM 视觉 API（识别食物、读营养成分表、读包装标签）
- DeepSeek API（估重与营养分析、AI 点评，默认 deepseek-v4-flash）
- 薄荷开放平台食物数据（开发期收集的常见份量参考库，内置 weight_refs.json）

## 快速开始

### 方式一：免费 HTTPS 托管（推荐）

1. 把 `foodlens-app` 文件夹拖到 [Netlify Drop](https://app.netlify.com/drop)（国内访问慢可改用腾讯云 EdgeOne Pages 或 CloudBase）
2. 部署完成后得到一个 `https://...` 网址
3. iPhone Safari 打开该网址 → 「分享」→「添加到主屏幕」
4. 打开 App → 「设置」页填写 API Key

### 方式二：局域网本地测试

```bash
cd foodlens-app
node server.js
```

手机连同一 Wi-Fi，Safari 打开终端显示的 `http://电脑IP:4173`。

## 配置说明

打开 App → 「设置」页：

1. **GLM API Key（必填）**：智谱开放平台（https://open.bigmodel.cn）免费创建
2. **DeepSeek API Key（强烈建议）**：https://platform.deepseek.com 创建，模型填 `deepseek-v4-flash`（公测，性能更强；异常会自动重试并降级到 `deepseek-chat`）
3. **参照物（推荐）**：选择「自定义卡片」，长填 11.2、宽填 6.8（工牌本体尺寸，不含挂扣）；拍照时把工牌平放在食物旁
4. 设置每日热量和三大营养素目标、身高体重
5. 保存后点「测试 GLM」「测试 DeepSeek」确认连接

密钥只保存在这台手机的浏览器本地，不会上传到任何服务器，也不会写入代码。

## 使用流程

1. 「今日」页：第一张拍俯视图（工牌平放食物旁）；可选再拍一张前上 45° 视角（工牌和食物都别动），两张图一起分析更准
2. 选餐次 → 「AI 估重分析」
3. 核对结果（重量/热量/营养素可直接修改；包装食品填实际数量自动折算）→ 「记录这一餐」
4. 「AI 饮食评价」结合训练计划点评当日饮食
5. 「食物库」添加常吃食物（可拍摄营养成分表自动识别）
6. 「身体」页记录体重和三围；「计划」页粘贴训练计划

## 数据与隐私

- 饮食记录、身体数据、自定义食物库都只存在当前手机的浏览器本地
- API Key 由用户自己在手机设置页输入，仅存本地
- 托管平台（如 Netlify）只存放公开的前端代码，不接触任何个人数据
- 换设备/重装时：先在旧设备「设置 → 导出备份」，再在新设备「导入备份」

## 常见问题

- **提示 429 访问量过大**：免费模型限流，App 会自动降级尝试备用模型，稍等重试
- **DeepSeek 返回格式异常/空内容**：已开启 JSON 模式 + 提高输出上限 + 自动重试和降级
- **iPhone 拍照按钮只唤起相机**：每个入口都配有「从相册选择」按钮
- **包装食品估不准**：AI 会优先读包装净含量，配合「数量」输入按 净含量÷总数×数量 计算
- **换网址/重装后数据没了**：先导出备份，新版本导入
